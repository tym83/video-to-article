# video-to-article

Плагин для [Claude Code](https://claude.com/claude-code), который превращает видео в готовую иллюстрированную статью.

На вход — ссылка на YouTube (или всё, что умеет скачать `yt-dlp`) либо локальный видео- или аудиофайл.
Плагин расшифровывает речь Whisper'ом, спрашивает, нужен ли перевод и на какой язык, обрабатывает
расшифровку по кускам, чтобы ничего не потерялось в пересказе, собирает структурированную статью, сверяет
её с расшифровкой, проводит литературную редактуру живым языком и корректуру, выдёргивает кадры из видео и
расставляет их по тексту, предлагает пять заголовков и умеет выгрузить результат в формате Хабра.

English version: [README.md](README.md).

## Что получается

```
video-to-article/<video-id>/
├── 01-source/          видео, аудио 16 кГц, метаданные
├── 02-transcript/      transcript.json / .txt / .srt (Whisper, таймкоды слов)
├── _context.md         спикеры, темы, глоссарий, ловушки распознавания, голос
├── 03-chunks/          куски до 2500 знаков, резанные по паузам, + манифест
├── 04-text/            каждый кусок переведён или вычищен (пять проходов)
├── 05-assembled.md     лид, структура H2/H3, цитаты, справки, заявки на иллюстрации
├── coverage.md         соотношение объёмов по кускам: ничего не ушло в пересказ
├── 05-factcheck.md     отчёт PASS/FAIL по сверке с расшифровкой
├── 06-edited.md        литературная редактура (+ журнал, + 06-factcheck.md: правка не изменила фактов)
├── 07-proofread.md     корректура (+ журнал)
├── 08-headlines.md     пять вариантов заголовка
├── 09-seo.md           план ключевых слов (по желанию)
├── frames/             кандидаты по сменам сцен и готовые иллюстрации
├── article.md          финальная статья с front matter и кадрами на местах
└── article.habr.md     выгрузка для Хабра (по желанию)
```

## Конвейер

| Этап | Кто | Что |
|---|---|---|
| 0 | скрипт | проверка `ffmpeg`, `yt-dlp`, Whisper; при нехватке — установка в venv |
| 1 | `fetch.py` | скачать видео (или взять файл), выделить аудио, собрать метаданные |
| 2 | `transcribe.py --detect-only` | определить язык и спросить: язык статьи, число кадров, SEO |
| 3 | `transcribe.py` + `frames.py scenes` | Whisper `large-v3` (faster-whisper, mlx-whisper или openai-whisper), детерминированное декодирование |
| 4 | `va-context-builder` | спикеры, темы, глоссарий, ловушки распознавания, голос |
| 5 | `chunk.py` + `va-chunk-writer` ×N + `coverage.py` | куски параллельно: буквально → как носитель → термины → живость → читка вслух; слишком короткие переделываются |
| 6 | `va-assembler` | структура, цитаты, справки, точки иллюстраций по сменам сцен |
| 7 | `va-fact-checker` | **гейт**: ничего не выдумано и не потеряно, имена, цифры и цитаты верны (до трёх кругов, дальше решаете вы) |
| 8 | `va-literary-editor` + `va-fact-checker` (сверка) | живой, богатый литературный язык — не инфостиль; затем проверка, что правка не изменила фактов |
| 9 | `proofcheck.py` + `va-proofreader` | типографика, орфография, пунктуация, согласование, единообразие |
| 10 | `va-seo-optimizer` | ключевые слова по желанию (Ahrefs MCP, если подключён) |
| 11 | `va-headline-writer` | **гейт**: пять типов заголовков, выбираете вы |
| 12 | `frames.py extract` | полноразмерные кадры по выбранным таймкодам, без чёрных и смазанных |
| 13 | `va-finalizer` | `article.md` с front matter, кадрами и ссылкой на источник |
| 14 | `habr.py` | выгрузка для Хабра по желанию |

Правила редактуры и корректуры (`references/ru-editing.md`, `references/ru-proofreading.md`) взяты из
издательского тулчейна для русских книг и справочника Лопатина: канцелярит, кальки, ложные друзья, ритм,
штампы, типографика (« », „ “, —, –, …, неразрывные пробелы), согласование числительных, слитное и дефисное
написание, чек-лист приёмки перевода. Для других языков агенты применяют те же принципы на этом языке.

## Установка

Как плагин из этого репозитория:

```
/plugin marketplace add tym83/video-to-article
/plugin install video-to-article@video-to-article
```

Или вручную: скопировать `skills/video-to-article` в `~/.claude/skills/`, а `agents/*.md` — в `~/.claude/agents/`.

Нужны `ffmpeg`, Python 3.10+ и пакеты `yt-dlp`, `faster-whisper` (или `mlx-whisper` на Apple Silicon, или
`openai-whisper`) и `pillow`. Если чего-то нет, скилл предложит поставить Python-часть в
`~/.venvs/video-to-article`.

## Использование

```
/video-to-article https://www.youtube.com/watch?v=…
/video-to-article ~/Movies/talk.mp4
```

После определения языка скилл задаёт три вопроса (язык статьи, сколько иллюстраций, нужен ли SEO),
останавливается на двух гейтах (фактчек, заголовок) и в конце предлагает выгрузку для Хабра.

## Хабр

Импорт Markdown на Хабре понимает заголовки на уровень выше обычного: название статьи — вообще не
заголовок (оно вводится в отдельное поле), а разделы начинаются с одной `#`. `habr.py` делает это
преобразование, переводит спецблоки в обычный Markdown и может вставить `<cut />` после лида.

## Скрипты отдельно

Все скрипты работают и без Claude:

```bash
S=skills/video-to-article/scripts
python3 $S/fetch.py "https://youtu.be/…" --workdir work
python3 $S/transcribe.py work/<id> --model large-v3-turbo
python3 $S/chunk.py work/<id>
python3 $S/frames.py work/<id> scenes
python3 $S/coverage.py work/<id> --mode translate --to ru
python3 $S/proofcheck.py article.md --lang ru --fix --report findings.md
python3 $S/habr.py article.md --cut
```

## Тесты

```bash
python3 -m unittest discover -s tests
```

Тесты проверяют типографику (код, ссылки, HTML, спецблоки и технические токены вроде `x86-64` или
`2026-10-09` не должны пострадать), выгрузку для Хабра, таймкоды, нарезку и контроль объёма.
